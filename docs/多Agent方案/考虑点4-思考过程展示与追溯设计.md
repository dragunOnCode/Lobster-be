## 看现状

### 当前实现程度

根据项目探索，当前系统的思考过程追溯能力：

**已实现：**
- ✅ **消息存储**：所有Agent响应存储在messages表
- ✅ **元数据记录**：messages.metadata字段可存储额外信息
- ✅ **会话历史**：可查询完整的对话历史
- ✅ **事件日志**：workspace的transcripts.jsonl记录操作事件

**当前缺失：**
- ❌ **思考过程分离**：思考内容混在消息中，无法单独查询
- ❌ **结构化存储**：思考过程是纯文本，缺少结构化字段
- ❌ **可视化展示**：前端无法展示思考树、推理链
- ❌ **追溯关联**：无法追溯某个决策的完整推理过程
- ❌ **CoT标记**：没有显式的Chain-of-Thought标记和解析

### 核心问题

**问题场景：**
```
用户：为什么Agent选择使用React而不是Vue？
系统：❌ 无法回答，思考过程未单独记录

用户：这个bug是在哪一步引入的？
系统：❌ 无法追溯，缺少决策树

用户：Agent为什么重试了3次？
系统：❌ 无法展示，评估结果未结构化存储
```

## 看业界

### 业界实践案例

#### 1. **LangSmith (LangChain)**

**方案：**
- 完整的Trace系统，记录每个LLM调用
- 树状结构：Run → Child Runs → Grandchild Runs
- 支持标签、元数据、输入输出、延迟、成本

**数据模型：**
```json
{
  "id": "run-123",
  "name": "AgentExecutor",
  "run_type": "chain",
  "inputs": { "input": "用户问题" },
  "outputs": { "output": "Agent响应" },
  "start_time": "2024-01-01T00:00:00Z",
  "end_time": "2024-01-01T00:00:05Z",
  "child_runs": [
    {
      "id": "run-124",
      "name": "LLMChain",
      "run_type": "llm",
      "inputs": { "prompt": "..." },
      "outputs": { "text": "..." }
    }
  ]
}
```

**优势：**
- 完整的调用链追溯
- 可视化界面（时间线、树状图）
- 支持成本分析和性能优化

**劣势：**
- 需要集成LangChain生态
- 数据量大（每次调用都记录）
- 查询复杂（嵌套结构）

#### 2. **OpenAI Function Calling Logs**

**方案：**
- 记录每次函数调用的参数和返回值
- 支持多轮对话的上下文追踪
- 提供Playground重放功能

**数据模型：**
```json
{
  "messages": [
    {
      "role": "assistant",
      "content": null,
      "function_call": {
        "name": "get_weather",
        "arguments": "{\"location\": \"Beijing\"}"
      }
    },
    {
      "role": "function",
      "name": "get_weather",
      "content": "{\"temperature\": 20}"
    }
  ]
}
```

**优势：**
- 简单直观
- 易于重放和调试
- 官方支持

**劣势：**
- 仅限函数调用，不包含内部推理
- 无法展示思考过程
- 缺少可视化

#### 3. **AutoGPT Logs**

**方案：**
- 详细的日志文件，记录每个步骤
- 包含：Thoughts、Reasoning、Plan、Criticism
- 支持JSON和Markdown格式

**数据模型：**
```json
{
  "thoughts": {
    "text": "我需要先搜索相关信息",
    "reasoning": "因为我不知道最新的数据",
    "plan": "- 搜索\n- 分析\n- 总结",
    "criticism": "搜索可能不够精确",
    "speak": "让我先搜索一下"
  },
  "command": {
    "name": "google_search",
    "args": { "query": "..." }
  }
}
```

**优势：**
- 结构化的思考过程
- 包含自我批判（Criticism）
- 易于理解

**劣势：**
- 文件存储，查询不便
- 无可视化界面
- 缺少关联关系

#### 4. **Anthropic Claude Artifacts**

**方案：**
- 将思考过程和最终输出分离
- Artifacts：可交互的结构化内容
- 支持代码、图表、文档等多种类型

**数据模型：**
```xml
<thinking>
我需要创建一个React组件...
考虑到性能，应该使用useMemo...
</thinking>

<artifact type="code" language="tsx">
export function MyComponent() {
  // 代码
}
</artifact>
```

**优势：**
- 清晰的思考与输出分离
- 支持多种内容类型
- 用户体验好

**劣势：**
- 需要特殊的XML标记
- 不支持嵌套思考
- 缺少历史追溯

#### 5. **Weights & Biases (W&B)**

**方案：**
- ML实验追踪平台
- 记录超参数、指标、模型版本
- 支持对比实验和可视化

**数据模型：**
```python
wandb.init(project="my-project")
wandb.log({
  "loss": 0.5,
  "accuracy": 0.9,
  "epoch": 1
})
```

**优势：**
- 强大的可视化
- 支持团队协作
- 丰富的图表类型

**劣势：**
- 面向ML训练，不适合Agent推理
- 需要额外的服务
- 学习曲线陡峭

## 思考过程

### 信息启发

从业界案例可以看出，思考过程追溯的核心要素：

1. **结构化存储**：不能只存文本，需要字段化
2. **层次关系**：思考是树状的，不是线性的
3. **时间序列**：需要记录每个步骤的时间戳
4. **关联追溯**：思考 → 行动 → 结果的完整链路
5. **可视化**：树状图、时间线、流程图

### 我们的场景特点

1. **多Agent协作**：
   - 每个Agent有独立的思考过程
   - Agent之间有握手转移
   - 需要展示整体的协作流程

2. **ReAct循环**：
   - Think → Act → Observe → Evaluate
   - 可能有多次迭代
   - 需要展示每次迭代的推理

3. **Plan-And-Execute**：
   - 有全局计划
   - 有局部执行
   - 需要展示计划与执行的对应关系

4. **用户需求**：
   - 开发者：需要调试和优化Agent
   - 最终用户：需要理解Agent的决策
   - 审计：需要追溯历史决策

### 方案抉择

| 维度 | 纯日志 | LangSmith | 自定义表 | 混合方案 |
|------|--------|-----------|---------|---------|
| **查询性能** | ❌ 差 | ⚠️ 中 | ✅ 好 | ✅ 好 |
| **可视化** | ❌ 无 | ✅ 强 | ⚠️ 需自建 | ✅ 强 |
| **灵活性** | ✅ 高 | ❌ 低 | ✅ 高 | ✅ 高 |
| **实现成本** | ✅ 低 | ⚠️ 中 | ⚠️ 中 | ❌ 高 |
| **集成难度** | ✅ 低 | ⚠️ 中 | ✅ 低 | ⚠️ 中 |

### 取舍标准

1. **可查询性优先**：使用PostgreSQL，支持复杂查询
2. **结构化存储**：专门的表结构，不混在messages中
3. **渐进式可视化**：先实现数据存储，再叠加可视化
4. **兼容现有架构**：复用现有的数据库和ORM

### 最终选择

**自定义表 + 结构化存储 + 前端可视化**

理由：
- 完全控制数据模型，灵活性最高
- 查询性能好，支持复杂分析
- 可以渐进式实现，先存储后可视化
- 不依赖外部服务，降低运维成本

#### 数据库设计

**表1：thought_traces（思考轨迹）**

```sql
CREATE TABLE thought_traces (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id UUID NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
  message_id UUID REFERENCES messages(id) ON DELETE CASCADE,
  agent_id VARCHAR(50) NOT NULL,

  -- 层次结构
  parent_trace_id UUID REFERENCES thought_traces(id), -- 父思考（用于嵌套）
  trace_type VARCHAR(20) NOT NULL, -- 'plan' | 'task' | 'react_loop' | 'evaluation'
  trace_level INT NOT NULL DEFAULT 0, -- 层级深度

  -- 思考内容
  title TEXT NOT NULL, -- 简短标题
  description TEXT, -- 详细描述
  reasoning JSONB, -- 结构化推理过程
  /*
  reasoning示例:
  {
    "goal": "实现登录功能",
    "context": "当前没有auth模块",
    "options": [
      { "option": "使用JWT", "pros": ["无状态", "易扩展"], "cons": ["需要刷新机制"] },
      { "option": "使用Session", "pros": ["简单"], "cons": ["有状态"] }
    ],
    "decision": "使用JWT",
    "rationale": "因为系统需要支持分布式部署"
  }
  */

  -- 状态
  status VARCHAR(20) NOT NULL DEFAULT 'in_progress', -- in_progress | completed | failed
  confidence_score DECIMAL(3,2), -- 0.00-1.00，思考的置信度

  -- 时间
  started_at TIMESTAMP DEFAULT NOW(),
  completed_at TIMESTAMP,
  duration_ms INT, -- 思考耗时

  -- 元数据
  metadata JSONB,

  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_thought_traces_session ON thought_traces(session_id, started_at DESC);
CREATE INDEX idx_thought_traces_message ON thought_traces(message_id);
CREATE INDEX idx_thought_traces_parent ON thought_traces(parent_trace_id);
CREATE INDEX idx_thought_traces_agent ON thought_traces(agent_id, session_id);
```

**表2：thought_steps（思考步骤）**

```sql
CREATE TABLE thought_steps (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  trace_id UUID NOT NULL REFERENCES thought_traces(id) ON DELETE CASCADE,
  step_index INT NOT NULL, -- 步骤序号
  step_type VARCHAR(20) NOT NULL, -- 'think' | 'act' | 'observe' | 'evaluate'

  -- 步骤内容
  content TEXT NOT NULL, -- 步骤的文本内容
  structured_data JSONB, -- 结构化数据
  /*
  structured_data示例（step_type='act'）:
  {
    "action": "write_file",
    "parameters": {
      "path": "src/auth.ts",
      "content": "..."
    },
    "tool_calls": [
      { "tool": "file_system", "operation": "write", "duration_ms": 50 }
    ]
  }
  */

  -- 输入输出
  inputs JSONB, -- 步骤的输入
  outputs JSONB, -- 步骤的输出

  -- 状态
  status VARCHAR(20) NOT NULL DEFAULT 'pending', -- pending | running | completed | failed
  error_message TEXT, -- 错误信息（如果失败）

  -- 时间
  started_at TIMESTAMP DEFAULT NOW(),
  completed_at TIMESTAMP,
  duration_ms INT,

  -- 元数据
  metadata JSONB,

  created_at TIMESTAMP DEFAULT NOW(),

  UNIQUE(trace_id, step_index)
);

CREATE INDEX idx_thought_steps_trace ON thought_steps(trace_id, step_index);
CREATE INDEX idx_thought_steps_type ON thought_steps(step_type, trace_id);
```

CREATE TABLE thought_evaluations (

#### 核心服务实现

**ThoughtTrackerService**

```typescript
// src/agents/services/thought-tracker.service.ts

import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';

@Injectable()
export class ThoughtTrackerService {
  constructor(
    @InjectRepository(ThoughtTrace)
    private readonly traceRepo: Repository<ThoughtTrace>,
    @InjectRepository(ThoughtStep)
    private readonly stepRepo: Repository<ThoughtStep>,
    @InjectRepository(ThoughtEvaluation)
    private readonly evalRepo: Repository<ThoughtEvaluation>
  ) {}

  /**
   * 开始一个新的思考轨迹
   */
  async startTrace(params: {
    sessionId: string;
    messageId?: string;
    agentId: string;
    parentTraceId?: string;
    traceType: string;
    title: string;
    description?: string;
    reasoning?: any;
  }): Promise<ThoughtTrace> {
    const parentTrace = params.parentTraceId
      ? await this.traceRepo.findOne({ where: { id: params.parentTraceId } })
      : null;

    const trace = await this.traceRepo.save({
      sessionId: params.sessionId,
      messageId: params.messageId,
      agentId: params.agentId,
      parentTraceId: params.parentTraceId,
      traceType: params.traceType,
      traceLevel: parentTrace ? parentTrace.traceLevel + 1 : 0,
      title: params.title,
      description: params.description,
      reasoning: params.reasoning,
      status: 'in_progress',
      startedAt: new Date()
    });

    return trace;
  }

  /**
   * 完成思考轨迹
   */
  async completeTrace(
    traceId: string,
    status: 'completed' | 'failed',
    confidenceScore?: number
  ): Promise<void> {
    const trace = await this.traceRepo.findOne({ where: { id: traceId } });
    if (!trace) throw new Error(`Trace ${traceId} not found`);

    const durationMs = Date.now() - trace.startedAt.getTime();

    await this.traceRepo.update(traceId, {
      status,
      confidenceScore,
      completedAt: new Date(),
      durationMs
    });
  }

  /**
   * 记录思考步骤
   */
  async recordStep(params: {
    traceId: string;
    stepType: 'think' | 'act' | 'observe' | 'evaluate';
    content: string;
    structuredData?: any;
    inputs?: any;
    outputs?: any;
  }): Promise<ThoughtStep> {
    // 获取当前最大步骤序号
    const lastStep = await this.stepRepo.findOne({
      where: { traceId: params.traceId },
      order: { stepIndex: 'DESC' }
    });

    const stepIndex = lastStep ? lastStep.stepIndex + 1 : 0;

    const step = await this.stepRepo.save({
      traceId: params.traceId,
      stepIndex,
      stepType: params.stepType,
      content: params.content,
      structuredData: params.structuredData,
      inputs: params.inputs,
      outputs: params.outputs,
      status: 'completed',
      startedAt: new Date(),
      completedAt: new Date(),
      durationMs: 0 // 可以在实际执行时测量
    });

    return step;
  }

  /**
   * 记录评估结果
   */
  async recordEvaluation(params: {
    traceId: string;
    stepId?: string;
    evaluatorAgentId?: string;
    evaluationType: string;
    criteria: any;
    overallScore: number;
    passed: boolean;
    suggestions?: any[];
  }): Promise<ThoughtEvaluation> {
    const evaluation = await this.evalRepo.save({
      traceId: params.traceId,
      stepId: params.stepId,
      evaluatorAgentId: params.evaluatorAgentId,
      evaluationType: params.evaluationType,
      criteria: params.criteria,
      overallScore: params.overallScore,
      passed: params.passed,
      suggestions: params.suggestions
    });

    return evaluation;
  }

  /**
   * 解析CoT标记
   */
  parseCoTMarkers(content: string): {
    thoughts: string[];
    reasoning: string[];
    actions: string[];
  } {
    const thoughts: string[] = [];
    const reasoning: string[] = [];
    const actions: string[] = [];

    // 匹配 <thinking>...</thinking>
    const thinkingRegex = /<thinking>([\s\S]*?)<\/thinking>/g;
    let match;
    while ((match = thinkingRegex.exec(content)) !== null) {
      thoughts.push(match[1].trim());
    }

    // 匹配 REASONING: ...
    const reasoningRegex = /REASONING:\s*(.+?)(?=\n\n|\n[A-Z]+:|$)/gs;
    while ((match = reasoningRegex.exec(content)) !== null) {
      reasoning.push(match[1].trim());
    }

    // 匹配 ACTION: ...
    const actionRegex = /ACTION:\s*(.+?)(?=\n\n|\n[A-Z]+:|$)/gs;
    while ((match = actionRegex.exec(content)) !== null) {
      actions.push(match[1].trim());
    }

    return { thoughts, reasoning, actions };
  }
}
```
